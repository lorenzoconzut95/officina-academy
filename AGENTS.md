# Officina Academy — Agent Instructions

## Purpose
This repository contains the public application code for Officina Academy.

## Source of truth
- Application code and public learning content live in this repository.
- Personal context, private history, habits, career notes, decisions and conversation archives MUST NOT be stored here.
- Private context belongs in a separate private repository named `officina-brain`.

## Working protocol
Before changing the Academy:
1. Read this file.
2. Read the relevant product/program files in this repository.
3. If the task depends on Lorenzo's personal context, retrieve only the relevant private context from `officina-brain`.
4. Never copy sensitive/private material from `officina-brain` into this public repository.
5. Implement the smallest useful change.
6. Preserve existing progress/localStorage compatibility unless a migration is explicitly planned.
7. Keep Officina project-based: build first, study just-in-time.
8. Record meaningful product decisions in the private Brain decision log, not in public source code.

## Product principles
- One active learning mission at a time.
- Concrete output each session.
- Evidence beats passive course completion.
- Avoid parallel curricula that create dispersion.
- Keep the UI simple, interactive, and usable as a daily study environment.

## Deployment
The live site is published from the `main` branch using GitHub Pages.
